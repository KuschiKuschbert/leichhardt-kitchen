Fix the glow before Diwali on Sunday 8 November

The gentle glow animates a drop shadow on the celebration drawing. On a slow phone that takes most of the main thread. The lighter, opacity-only glow already exists in css/seasonal-brand.css, but css/seasonal-effects.css loads after it and defines an animation with the same name, so the heavy one wins.
