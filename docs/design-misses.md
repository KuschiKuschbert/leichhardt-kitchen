# Design misses

Changes the head chef had to rework: too loud, too crowded, or in the wrong place. Most were found after they went live; the Found column says which were caught in a preview, and which the record does not say. Each row is a real case from [head-chef-decisions.md](head-chef-decisions.md), so the council can check a new proposal against what has already gone wrong. It sits beside [Where it goes, and how loud it is](design-patterns.md#where-it-goes-and-how-loud-it-is), which is the rule these cases lead to, and the service council pastes both into its evidence packet (`.claude/skills/service-council/SKILL.md`, Where it goes).

**Status, 26 November 2026: for the head chef to correct.** The first twelve rows come from the written record ([head-chef-decisions.md](head-chef-decisions.md)); the next six come from the bodies of merged pull requests (13 to 23 November), read the same day, and cite the pull request number. The "What the record says" and "What was chosen" columns restate what those sources say and add no cause they do not give; numbers are theirs. The last column is a question proposed from each case, not a decision. A row the head chef calls wrong, or a case neither source holds, is changed here first.

**Add a row** whenever something is reworked after use: the date and decision, what the record says, what was chosen, and one question that would have caught it. Keep each cell short.
