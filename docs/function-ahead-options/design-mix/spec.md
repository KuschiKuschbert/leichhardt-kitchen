## The mix in one sentence

Each person gets C's Function this week card once on Home, directly under Your day, and Got it collapses it in place to A's quiet Next function line, which answers "Got it. Kept here as one line" with Undo inside it; from 3 functions not yet seen, one combined card with one Got it; the work pages show A's line in the band's slot only on days the band would be empty, status words first, sized when the page opens for the tallest words it can become (B's open-only rule), and only a function today breaks that lock; Home's slot keeps the same lock; Orders gets B's Not ordered yet tag inside the existing function stock line; `#/fn` looks 7 days ahead and the sheet shows guests on its first line (A).
