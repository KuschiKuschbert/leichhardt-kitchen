# Preview fonts

Bundled for consistent, offline design review. These are the Kitchen Book's existing Google Fonts families, downloaded from Google's CSS/font endpoints on 9 November 2026, not new production dependencies.

- Barlow: regular 400, semibold 600 and bold 700.
- Barlow Condensed: semibold 600 and bold 700.
- Caveat: semibold 600 and bold 700.

`fonts.css` maps the original file names to each family and weight. Each family is distributed under the SIL Open Font License 1.1; its complete licence is in the matching `*-OFL.txt` file in this folder. Original licence sources: the `ofl/barlow`, `ofl/barlowcondensed` and `ofl/caveat` directories in the Google Fonts repository.

The standalone download embeds these same bytes. Neither the font files nor the preview are loaded by the production app.
