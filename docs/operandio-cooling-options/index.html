LEICHHARDT KITCHEN BOOK · SELECTED DESIGN

A small clock. Two cooling timers.

Operandio opens as a compact dropdown, with the same cream, charcoal and orange as the chef hat menu.

Try it

One tick at a time.

  1. Tick 2 hours. Anyone in the kitchen can start it. Everyone sees the same countdown.
  2. The first timer ends. Everyone gets “Operandio batch cooling time 2 hours is done.” The 4-hour row becomes available.
  3. Someone ticks 4 hours. A further four hours starts from that tick. It does not start automatically.
  4. The second timer ends. Everyone gets “Operandio batch cooling time 4 hours is done.”

When the app is closed.

The chosen design includes a timer saved on the server and a phone notification when each stage ends. Reopening the app shows the same deadline.

Each device needs notifications enabled. iPhone and iPad need the app added to the Home Screen. Phone settings and connectivity can delay or silence notifications.

Clickable preview only. Times and people are examples. Starts and acknowledgements are simulated locally. No real timer, account, notification permission or message is used. Background delivery still needs a server implementation and deployment. The recommended Firebase task queue requires a separate change from the recorded free-plan choice to billing-enabled Firebase; no plan has been changed.
